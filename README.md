# FlowMonitor FANET Audit

This repository contains the analysis scripts, raw data, and results for the paper:

"Undocumented Limitations of NS-3 FlowMonitor in FANETs: An Empirical Audit"

## Overview

This repository provides the complete reproducibility package for the empirical audit of NS-3.47 FlowMonitor in FANET scenarios. It includes:

- 12 analysis scripts (Python) that process FlowMonitor XML output and JSON metrics.
- 1 C++ benchmark (test_L7.cc) that measures the O(n) complexity of FindFlow().
- Raw simulation data for 25 baseline SLAM runs, 25 runs with MaxPerHopDelay=2s, and 105 CBR validation runs.
- L12 simulation logs for 7 durations (N=30, seed=42).
- Results (CSV) generated by the analysis scripts.

## How to Reproduce

### Prerequisites

- NS-3.47 (https://www.nsnam.org/)
- Python 3.8+
- GCC 11.4 (for L7 benchmark)

### Reproducing L1-L6, L8-L12 (Python scripts)

Run each script to generate the corresponding table:

    cd flowmonitor-fanet-audit
    python3 scripts/verify_L1.py
    python3 scripts/verify_L2.py
    python3 scripts/verify_L3.py
    python3 scripts/verify_L4.py
    python3 scripts/verify_L5.py
    python3 scripts/verify_L6.py
    python3 scripts/verify_L8.py
    python3 scripts/verify_L9.py
    python3 scripts/verify_L10.py
    python3 scripts/verify_L11.py
    python3 scripts/verify_L12.py

The results are saved in results/LN/LN_results.csv.

### Reproducing L7 (C++ benchmark)

    cp scripts/test_L7.cc /path/to/ns-3.47/scratch/
    cd /path/to/ns-3.47
    ./ns3 build scratch/test_L7
    ./ns3 run --no-build scratch/test_L7 > ~/flowmonitor-fanet-audit/results/L7/L7_results.csv

Note: The absolute times in L7 depend on the hardware and compiler. The benchmark uses #pragma GCC optimize("O0") and a function pointer to prevent compiler optimizations. On a different machine, the absolute values may differ, but the linear growth with N (O(n) complexity) should be the same.

### Reproducing L12 (simulations + log analysis)

The L12 logs are included in data/raw/L12_logs/. To reproduce them from scratch, run:

    cd /path/to/ns-3.47
    ./path/to/flowmonitor-fanet-audit/scripts/run_L12.sh

Then analyze the logs:

    python3 scripts/verify_L12.py
